A [make.fun](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) bounty entry. The program writes one funny final text from a phone at one percent battery to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt`. The line is 158 characters, one line, plain UTF-8, inside the 200 character gate.

## The line

> 1%. quick, before I go: I saw your search history, all of it, and I'm taking it to the grave with me. tell my charger I loved him. it's been an honor. mostly.

The joke is the phone dying with leverage. It knows everything, it tells you so with its last breath, and it still finds time for a goodbye to the charger.
